# 🎵 Playnck

> A modern, lightweight, and beautiful desktop music player built with Electron.

Playnck is a feature-rich local music player focused on speed, simplicity, and an enjoyable listening experience. It combines a clean interface with powerful music library management, automatic metadata support, and a highly customizable visual experience.

Originally started as **Gem Player**, the project has grown into **Playnck**, with a complete redesign, new architecture, and many additional features.

---

## ✨ Features

- 🎵 Beautiful modern desktop interface
- 📁 Fast local music library management
- 🏷️ Automatic metadata detection
- 🖼️ Album artwork support
- 🎨 Smooth visual effects and animations
- 🌈 Custom themes
- 🔍 Fast searching
- 📂 Drag & Drop support
- 🎼 Playlist management
- ⚡ Lightweight and responsive
- 💻 Cross-platform (Electron)

---

## 🚀 Why Playnck?

Most desktop music players are either:

- outdated
- overloaded with unnecessary features
- slow
- visually unappealing

Playnck aims to solve that by offering a player that is:

- Modern
- Fast
- Clean
- Responsive
- Easy to use
- Pleasant to look at

Every feature is designed around making your music library enjoyable without getting in your way.

# Installation

Clone the repository

```bash
git clone https://github.com/FakharArrazi/Project-Playnck.git
```

Move into the project

```bash
cd Project-Playnck
```

Install dependencies

```bash
npm install
```

Run Playnck

```bash
npm start
```

---

# Building

To create a production build

```bash
npm run build
```

If your project contains a release script

```bash
npm run release
```

The generated application will be placed inside the `dist/` folder.
